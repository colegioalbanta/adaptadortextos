Guía de Uso y Clave de API

🔑 Obtén tu API Key Gratuita de Google Gemini

Sigue estos tres sencillos pasos para vincular tu cuenta:

  1. Accede al portal oficial de Google AI Studio.
  2. Haz clic en "Get API Key" y posteriormente en "Create API Key".
  3. Copia la clave generada (comienza por AIzaSy...) y pégala en el panel lateral de la app.

📄 Archivos compatibles

Puedes subir directamente documentos en formato .pdf, .docx o .doc. La aplicación extraerá el contenido automáticamente para adaptarlo.
